Common questions

No email after 24 hours?
Check the spam folder first — the code is a long plain-text line, which filters occasionally dislike. If it is not there, write to contact@qiaodesktop.com from the address you paid with, and mention the order date.
I entered the Machine Code of another computer
Reply with the right one (see above). One code works on one machine, so a wrong Machine Code is the single most common reason a code will not activate.
I am replacing this PC, or reinstalling Windows
Reinstalling Windows needs no new code — the Machine Code is derived from your system disk serial and CPU model, and a reinstall changes neither.
Replacing the system disk or the CPU does. Re-signing is free but limited: once per 12 months, at most 3 times in total, and only within 36 months of purchase. Send the new Machine Code from the email address you originally paid with — keep that receipt, it is your proof of purchase. The licence is personal, bound to one machine for life, and non-transferable.
