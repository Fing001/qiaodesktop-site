隐私政策

巧桌面与本站对您的数据做了什么 — 尽量说得直白。

最近更新：2026 年 10 月 22 日  ·  适用范围：巧桌面桌面程序与 qiaodesktop.com

一句话版本

桌面程序只在每天首次启动时向官网问一次“有没有新版本”，请求里只有版本号，没有任何能指向您的东西。没有遥测、没有使用统计、没有崩溃上报。它知道的其它一切，都留在您自己电脑上的一个文件夹里。

本站不要账号，也不设自有 Cookie。托管方只做不含 Cookie 的汇总访问统计。

两个联系页会加载腾讯在线咨询组件，该组件会写入少量 Cookie。不想被写入就别进联系页，直接发邮件 — 地址在那一页上。

一、本政策的适用范围

本政策覆盖两件事：面向 Windows 的巧桌面桌面程序（下称“本程序”），以及 qiaodesktop.com 本站（下称“本站”）。它不覆盖我们链接到的任何第三方网站。

二、桌面程序

2.1 它只在一种情况下联网：检查更新

本程序每天最多向 qiaodesktop.com 发送一次版本查询，用来知道有没有新版本。这条请求里只有两项内容：当前程序的版本号与分发渠道（官网版 / 商店版）。没有设备标识、没有硬件指纹、没有安装编号、没有您的文件路径或文件名、没有使用行为记录 — 也就是说，这条请求里没有任何东西能把两台电脑区分开。我们由此最多只能看出“某天某个版本被查询过多少次”，看不出是谁。

它同时就是更新检查本身，不是统计工具：我们不做使用统计、不上报崩溃、不采集广告标识。断网时本程序的全部功能完全一致，只是不会提示新版本。

不想要这条请求：进入设置中心 → 通用设置，取消勾选“每天检查一次新版本”。关闭后本程序不再发出任何网络请求 — 一个字节都不发。

2.2 它保存什么、保存在哪

全部数据都位于您自己电脑上的 %APPDATA%\QiaoDesktop\，该文件夹中的内容不会被上传到任何地方。

文件 / 文件夹内容
qd_config.json您的盒子、位置与尺寸、文件面板与壁纸设置、界面语言，以及您已映射的文件夹路径。
qd_notes.json您在便签里输入的文本，按便签分条、以纯文本保存。
shortcuts\您拖入盒子的快捷方式文件。
debug\错误日志 — 仅在出错时写入，正常启动不会产生。

2.3 它为什么要读取您的文件

为了在盒子里画出图标、文件名和缩略图，本程序会从您的磁盘读取文件与文件夹列表，并从文件本身提取图标。映射盒显示的就是您指定的那个文件夹里的内容。以上全部在本地内存中完成，只产出屏幕上的像素 — 文件内容不会被传输、不会被复制到别处，也不会进入任何数据库。

2.4 试用期与激活

15 天全功能试用从首次启动开始计算，只把起始时间戳写入上面的配置文件夹。激活码完全在您的机器上校验：程序用内置的公钥验证签名，再比对硬件指纹，确保一个激活码不能换到另一台电脑上使用。校验过程不向我们发送任何请求，我们也不会收到您激活的通知。

2.5 错误日志

出错时，本程序可能在 debug\ 下写一份简短的纯文本日志，其中可能包含出错涉及的文件路径。日志只留在您的磁盘上，从不上传，您可以随时删除。

2.6 如何清除数据

删除 %APPDATA%\QiaoDesktop\ 即可清除全部程序数据。移除本程序时不会自动删除该文件夹，因为里面也存着您的布局 — 想要一个干净的开始，请自行删除。

三、本站

3.1 不要账号、没有表单

本站没有登录、没有注册、没有评论框，也没有联系表单。全站不会向您索取姓名、地址或电话号码。

3.2 本站自己设置的 Cookie

没有。我们的页面不在 Cookie、localStorage 或 sessionStorage 中写入任何内容。在线演示是一段自包含的动画，不记录任何事件。

3.3 Cloudflare Web Analytics

本站托管在 Cloudflare Pages，它会在每个页面附加一个不含 Cookie 的统计信标，用于汇总页面浏览量、来源、国家与设备类型。Cloudflare 声明该服务不使用 Cookie、不做访客指纹识别、不跨站追踪，因此无法把您识别为某个具体个人。

3.4 联系页：腾讯在线咨询组件

我们的两个联系页会从腾讯云加载在线咨询组件（trtc.io）。这是全站唯一超出“统计浏览量”范围的部分。加载期间，它可能会：

  • 写入名称以 sa_jssdk_、sajssdk_ 开头的 Cookie，内容包括一个匿名访客 ID、是否首次访问的标记，以及您的流量来源与来路页面；
  • 在 localStorage 中保存名为 visitorId-… 的值，以便下次访问时识别同一个访客；
  • 向 api.trtc.io 与 sc-rp.tencentcloud.com 发送请求。

该组件由腾讯提供并运营，其数据处理遵循腾讯自己的隐私政策（见下表链接）。我们不会从中获得您的 IP 地址或浏览记录：我们只能看到您主动发送的咨询内容，仅此而已。

3.5 如何避开该组件

不进联系页，上述行为都不会发生 — 本站其他页面不加载它。如果您需要在不加载它的情况下联系我们，请用页面最下方的邮箱。您也可以在浏览器中阻止第三方 Cookie 或跨站脚本，本站其余部分仍可正常使用。

五、邮件

如果您给我们发邮件，我们会收到您的邮箱地址、您署名时留下的姓名，以及您写下的内容。这些只用于回复您和记录问题。我们不会把您加入邮件列表，不用于营销，也不出售或转交他人。您随时可以要求我们删除往来邮件。

六、关于儿童

本程序与本站都是通用桌面整理工具，并非面向儿童设计。我们不会在知情的情况下收集儿童的个人信息 — 而本程序根本不收集任何信息，儿童使用它也没有信息可以交出去。

七、您的权利

由于我们手上没有来自本程序的任何您的数据，多数请求您用自己的文件管理器就能完成。对于确实到达我们这边的信息 — 您发出的邮件、您输入的咨询内容 — 您可以要求查看、更正或删除，我们会照办。请写信到下方地址。

八、政策变更

如果本程序或本站新增了影响隐私的功能，我们会先更新本页并修改顶部的日期；重要变更还会写入程序的更新说明。

九、联系我们

关于本政策或数据处理的任何问题：contact@qiaodesktop.com。我们的联系页列出了建议随信附上的信息，便于我们尽快答复。
